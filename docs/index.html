Questions?
We've got you.

A few helpful details before you install SubhuMusic.

Is SubhuMusic an Android app?

Yes. SubhuMusic is an Android music player. This website introduces the app and links to its official GitHub releases.

Does the download button always get the newest version?

Yes. The button uses GitHub's latest-release download route for the file named SubhuMusic-Android.apk. When a new release is published with that same asset filename, the button automatically points to it.

Which Android devices are supported?

The current release targets Android 6.0 and newer, and this APK is built for the ARM64-v8a architecture. Check your device's compatibility before installing.

Can I listen offline?

You can play music stored on your device and use the app's supported download feature for offline listening. Online availability and download eligibility can vary by source, region and rights.

Are lyrics always synchronised?

Lyrics are supported, and synchronised lyrics can be shown when available for a track. Availability is not guaranteed for every song.

Is SubhuMusic affiliated with YouTube or Google?

No. SubhuMusic is an independent project and is not affiliated with, endorsed by or officially connected to YouTube, YouTube Music, Google or any music streaming service.

Where can I report a problem or suggest a feature?

Visit the GitHub issue tracker to report bugs or share ideas. Include your app version, Android version, device model and steps to reproduce the issue. Never post passwords or private keys.
